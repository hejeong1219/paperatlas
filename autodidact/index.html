최근 10년 인간 암 연구에서 단백체, 인산화 단백체, 아세틸 단백체가 어떻게 측정되었는지, 그리고 TMT/iTRAQ/DIA, IMAC/TiO2, K-ac enrichment, Orbitrap 장비가 결과 해석에 어떤 의미를 갖는지 공부하기 위한 한글 인터랙티브입니다.

학습 포인트

숫자 자체보다, 왜 그 숫자가 나왔는지와 어떤 연구 질문에 쓰이는지를 먼저 잡습니다.

point 01

Proteome은 RNA-seq의 빈칸을 메웁니다

RNA abundance와 protein abundance는 항상 일치하지 않습니다. proteogenomics는 mutation, copy-number, RNA 변화가 실제 protein abundance와 pathway로 이어지는지 확인합니다.

protein abundancecopy-number dosage

point 02

Phosphoproteome은 signaling 상태를 봅니다

하나의 단백질에 여러 phosphorylation site가 있으므로 phosphosite count는 protein count보다 훨씬 커질 수 있습니다. kinase activity와 druggable pathway 해석에 핵심입니다.

kinase signalingsite localization

point 03

Acetylome은 선택적이지만 해석력이 큽니다

K-ac enrichment는 샘플량과 antibody specificity 부담이 커서 적게 등장하지만, chromatin regulation과 metabolic state를 연결하는 단서를 줍니다.

K-ac peptidechromatin/metabolism

MS workflow를 먼저 잡기

논문 Methods에서 이 순서대로 보면 identification count의 차이를 해석하기 쉬워집니다.

01 SAMPLEtumor / NAT / cell lineFFPE, fresh frozen, tumor purity, cohort 규모가 coverage를 좌우합니다.
02 DIGESTprotein → peptide대부분 trypsin digestion 후 peptide 단위로 LC-MS/MS에 들어갑니다.
03 LABELTMT · iTRAQ · LFQ · DIA상대정량, label-free, DIA 전략에 따라 비교 가능성이 달라집니다.
04 FRACTIONbRPLC / high-pH RP복잡도를 낮춰 더 많은 peptide를 식별하지만 instrument time이 늘어납니다.
05 ENRICHIMAC · TiO2 · K-ac IPPTM peptide는 abundance가 낮아 enrichment가 핵심입니다.
06 SEARCHFDR · localizationdatabase search와 site localization 기준이 최종 count를 결정합니다.

방법론을 한눈에 보기

각 방법론이 무엇을 해결하는지, count를 어떻게 읽어야 하는지, 무엇을 조심해야 하는지 카드로 정리했습니다.

TMT / TMTpro

여러 샘플을 한 번에 상대정량하는 cohort proteomics의 주력 방식

강점
tumor cohort 간 subtype/pathway 비교에 좋고 protein/phosphosite coverage가 큼
count 읽기
reference channel, plex 수, fraction 수가 식별 수에 영향
주의
ratio compression과 batch design 확인

iTRAQ

초기 CPTAC/대형 proteogenomic atlas에서 보이는 multiplex labeling

강점
2016년 전후 초기 proteogenomics 연구를 이해하는 기준점
count 읽기
최신 TMTpro 연구와 plex 수, instrument 성능이 다름
주의
옛 연구와 최신 연구의 count를 직접 서열화하지 않기

Label-free / LFQ / DIA

label 없이 많은 샘플을 반복 측정하거나 DIA로 재현성을 높이는 전략

강점
clinical cohort, FFPE 확장, biomarker 검증에 유리
count 읽기
missing value, library/search strategy, batch correction을 함께 봄
주의
run-to-run variability와 normalization 확인

IMAC / TiO2

phosphopeptide를 농축해 kinase signaling을 site 단위로 보는 방법

강점
drug response, pathway activation, kinase-substrate 해석에 강함
count 읽기
phosphosite 수는 protein 수보다 클 수 있고 site localization/FDR이 중요
주의
class I site, localization probability 기준 확인

K-ac enrichment

acetylated lysine peptide를 농축해 acetylome을 보는 방법

강점
chromatin regulation, metabolism, stress response의 단서를 제공
count 읽기
acetylsite count는 phosphosite보다 작고 연구별 편차가 큼
주의
antibody specificity와 샘플량, fractionation 부담 확인

Orbitrap 계열 장비

Fusion/Lumos, Q Exactive/HF/HF-X가 이 corpus의 중심 MS platform

강점
high-resolution MS/MS와 TMT/PTM workflow에 널리 사용
count 읽기
장비 모델, LC gradient, fraction 수가 identification 깊이에 영향
주의
장비명만 보고 단정하지 말고 workflow 전체를 같이 보기

Interactive plot: 대표 수치와 연구 지형

단백체·인산화체·아세틸체 식별 수, 연도·암종·방법론·장비 분포를 버튼으로 바꿔 봅니다.

Phosphosite countsite localization, class I site, phosphoprotein 수와 구분합니다.
Acetylsite countK-ac enrichment가 있는 연구만 비교하고, cohort study와 cell perturbation을 나눠 봅니다.
