개념 1

Identification count는 “검출 깊이”의 지표

protein group, unique peptide, phosphosite, acetylsite는 서로 다른 단위입니다. 따라서 숫자는 같은 축에서 단순 비교하기보다, 어떤 오믹스 레이어를 얼마나 깊게 봤는지로 읽어야 합니다.

개념 2

Phosphosite 수가 protein 수보다 커지는 이유

하나의 단백질에 여러 phosphorylation site가 있고, kinase signaling은 site 단위 해석이 중요합니다. 그래서 phosphoproteome은 protein abundance보다 훨씬 큰 count가 나올 수 있습니다.

개념 3

Acetylome은 아직 선택적으로 쓰임

K-ac peptide enrichment는 샘플량과 antibody specificity의 영향을 많이 받습니다. 그래서 대형 tumor cohort에서는 proteome/phosphoproteome보다 덜 자주 등장합니다.

MS workflow를 먼저 잡기

식별 수는 샘플, labeling, fractionation, enrichment, instrument, database search가 합쳐진 결과입니다.

01 SAMPLEtumor / NAT / cell lineFFPE, fresh frozen, tumor purity, cohort 규모가 coverage를 좌우합니다.
02 DIGESTprotein → peptide대부분 trypsin digestion 후 peptide 단위로 LC-MS/MS에 들어갑니다.
03 LABELTMT · iTRAQ · LFQ · DIA상대정량, label-free, library 기반 전략에 따라 비교 가능성이 달라집니다.
04 FRACTIONbRPLC / high-pH RP복잡도를 낮춰 더 많은 peptide를 식별하지만 instrument time이 늘어납니다.
05 ENRICHIMAC · TiO2 · K-ac IPPTM peptide는 abundance가 낮아 enrichment가 핵심입니다.
06 SEARCHFDR · site localizationdatabase search와 site localization 기준이 최종 count를 결정합니다.

방법론을 한눈에 보기

표 대신 카드로 바꿨습니다. 각 방법론이 무엇을 해결하는지, count를 어떻게 읽어야 하는지, 무엇을 조심해야 하는지 바로 보이게 했습니다.

TMT / TMTpro

여러 샘플을 한 번에 상대정량하는 cohort proteomics의 주력 방식

강점
tumor cohort 간 subtype/pathway 비교에 좋고 protein/phosphosite coverage가 큼
count 읽기
reference channel, plex 수, fraction 수가 식별 수에 영향
주의
ratio compression과 batch design 확인

iTRAQ

초기 CPTAC/대형 proteogenomic atlas에서 자주 보이는 multiplex labeling

강점
2016년 전후 초기 proteogenomics 연구를 이해하는 기준점
count 읽기
최신 TMTpro 연구와 plex 수, instrument 성능이 다름
주의
옛 연구와 최신 연구의 count를 직접 서열화하지 않기

Label-free / LFQ / DIA

label 없이 많은 샘플을 반복 측정하거나 DIA로 재현성을 높이는 전략

강점
clinical cohort, FFPE 확장, biomarker 검증에 유리
count 읽기
missing value, library/search strategy, batch correction을 함께 봄
주의
run-to-run variability와 normalization 확인

IMAC / TiO2

phosphopeptide를 농축해 kinase signaling을 site 단위로 보는 방법

강점
drug response, pathway activation, kinase-substrate 해석에 강함
count 읽기
phosphosite 수는 protein 수보다 클 수 있고 site localization/FDR이 중요
주의
class I site, localization probability 기준 확인

K-ac enrichment

acetylated lysine peptide를 농축해 acetylome을 보는 방법

강점
chromatin regulation, metabolism, stress response의 단서를 제공
count 읽기
acetylsite count는 phosphosite보다 작고 연구별 편차가 큼
주의
antibody specificity와 샘플량, fractionation 부담 확인

Orbitrap 계열 장비

Fusion/Lumos, Q Exactive/HF/HF-X는 이 corpus의 중심 MS platform

강점
high-resolution MS/MS와 TMT/PTM workflow에 널리 사용
count 읽기
장비 모델, LC gradient, fraction 수가 identification 깊이에 영향
주의
장비명만 보고 성능을 단정하지 말고 workflow 전체를 같이 보기
