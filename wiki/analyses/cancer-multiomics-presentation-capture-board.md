# Cancer Multiomics Presentation Capture Board

This page exists only to make presentation preparation easier: each row is one question-centered graph or HTML capture target for the advanced genetics LLM-Wiki presentation.

## Key Points

- Do not show one giant wiki graph for the whole talk. Show one question at a time.
- Each capture should answer: **what question did I ask, which nodes did I reopen, what gap did I see, and what next question did that create?**
- The user's own rules are general hypothesis-building rules for using LLM-Wiki, not biological categories.
- The previous cancer resistance review is included as a short background thought-chain, not as the main topic.
- The main Cancer Multiomics arc is: layer-centered marker discovery -> state-centered interpretation -> functional resistance-state research question.

## PPT Spine

1. Why I needed LLM-Wiki: paper summaries alone did not preserve how the question changed.
2. My operating rule: do not stop at "which layer"; ask "which tumor state does this layer read?"
3. Starting problem: cancer multiomics marker discovery was too layer-centered.
4. Reframing: WGS/proteome/phosphoproteome are different state readouts.
5. Sub-thought-chain: immune-evasion state from the cancer resistance framework.
6. Sub-thought-chain: kinase/adaptive-signaling state from PTM/phosphoproteome pages.
7. Data-structure sub-question: which data structure allows which state analysis?
8. Functional state map: immune-evasion, kinase/adaptive, DNA-repair/stress, stromal/access-limited, refractory mixed.
9. Final research question: can cancer multiomics reclassify genome-unexplained resistance into functional resistance states?
10. Next step: define feature sets and validation criteria for each state.
